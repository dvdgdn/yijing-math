# Linear information controls

Full-context exploratory research for INV-0007; this is not an isolated verification.

`linear_information.py` enumerates rank-three binary linear labels on six bits in two independent ways, compares their coin-noise information by exact integer products, and checks polynomial identities for an all-noise majorization proof. Decimal logarithms provide displayed values only.

```bash
python3 -I compute/experiments/INV-0007/linear_information.py --out /tmp/linear-information-reproduction.json
```

Use a fresh output path. The final script and `investigations/INV-0007-linear-information-controls/results.json` are frozen with the research report. Mathematical scope, proof and limitations are in that report.
