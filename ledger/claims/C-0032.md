## Statement

Under the coins model the primary hexagram is uniform, the primary→changed transition is exactly the product binary symmetric channel with crossover 1/4, and the set of moving lines is independent of the primary hexagram; I(primary; changed) = 6[1 − h₂(1/4)] ≈ 1.13233 bits. Under the yarrow-standard model the primary hexagram is uniform, P(change | yang) = 3/8 and P(change | yin) = 1/8, each changed line is yang with probability 3/8, I(primary; changed) ≈ 1.23261 bits and I(primary; moving-line set) ≈ 0.37367 bits. Under both models each line moves with probability 1/4, so the number of moving lines is Binomial(6, 1/4).
