## Statement

With 49 stalks, hanging one stalk from the right heap and counting both heaps by fours: if the left heap is uniform on 1, …, n−1, the line values have P(6) = 77/1612, P(9) = 5957/26832 (ratio 4.65), P(primary yang) = 14565731/29112720 ≈ 0.500322, P(change | yang) ≈ 0.4437, P(change | yin) ≈ 0.0956, and the moving-line set carries ≈ 0.709 bits about the primary hexagram. With binomial splits the textbook 1/16, 5/16, 7/16, 3/16 are reproduced to about 10⁻⁶.
