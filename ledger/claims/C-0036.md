## Statement

For an eight-valued label λ: I(λ;Y) = H(λ) − β(λ)·p log₂(1/p) + O(p) as p → 0, and I(λ;Y) = W₁(λ)·ρ²/(2 ln 2) + O(ρ⁴) as ρ = 1 − 2p → 0. Trigram: β = 3, W₁ = 3; palace: β = 4, W₁ = 13/8; generation: β = 6, W₁ = 0. Among balanced eight-valued labels, β ≥ 3 and W₁ ≤ 3, both attained by partitions into coordinate 3-subcubes; ‖s(A)‖² ≤ 192 for every 8-subset A of {0,1}⁶, with equality exactly for coordinate 3-subcubes. The generation label attains the worst possible values β = 6 and W₁ = 0.
